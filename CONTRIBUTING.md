# Contributing / 贡献说明

**We are not accepting external contributions at this time.** Pull requests from outside the project will be closed without review. Bug reports and suggestions are welcome as GitHub issues.

The project is licensed under AGPL-3.0 and its official apps are distributed through app stores, so a Contributor License Agreement (CLA) has to be in place before outside code can be merged. This file will be updated once that is decided.

---

**目前暂不接受外部贡献。** 来自项目外部的 Pull Request 会被直接关闭，不做评审。欢迎通过 GitHub issue 反馈问题和建议。

本项目采用 AGPL-3.0 许可证，官方 App 通过应用商店分发，因此在合并外部代码之前需要先确定贡献者许可协议（CLA）。确定后会更新本文件。
