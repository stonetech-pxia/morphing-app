## 验收清单（§10）

- [x] README 列明无需付费 API key 的本地启动步骤
- [ ] 用户始终处在同一个 App / workspace（M1）
- [ ] 自然语言改主页布局；预览、确认、取消可用；无法理解时有明确提示（M1）
- [ ] 任何 patch 都不能让受保护入口不可达（M1）
- [ ] 重启后界面与已安装工具状态仍在（M1 / M2）
- [ ] PDF 工具可安装、可打开、可执行并导出（M2）
- [ ] 修改 PDF 工具不会产生第二个工具实例（M2）
- [ ] 卸载 PDF 工具后文件仍在（M2）
- [ ] 恢复上一版本，不删文件，行为符合 §7E（M1）
- [ ] 旧 `schemaVersion` 快照的迁移测试（M1）
- [ ] 不合法 patch 被拦截；出错不白屏（M1）
- [ ] Schema、patch、工具动作、回滚有自动测试（M1 / M2）
- [x] TypeScript 检查、lint、基础测试可通过（M0 骨架层面）

## 明确不做

见 §3「明确不做」：不在手机上执行 AI 生成的代码、不做工具市场与付费、不做后台自主行动和语音主界面、不生成多个独立 App。
