## 已知限制

- 模拟器上只做了截图级验证（首页、AI 修改页）。点击操作需要 `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` 之后才能自动化；目前交互流程由 Jest UI 测试覆盖。
- SQLite 存储实现没有自动测试（Jest 环境无法运行原生 SQLite），与内存实现共用同一接口和语义。

## 明确不做

见 §3「明确不做」：不在手机上执行 AI 生成的代码、不做工具市场与付费、不做后台自主行动和语音主界面、不生成多个独立 App。
