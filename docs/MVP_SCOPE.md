- [x] README 列明无需付费 API key 的本地启动步骤

- [x] 自然语言改主页布局；预览（修改前/后）、确认、取消可用；无法理解时有明确提示

- [x] 恢复上一版本，不删文件，行为符合 §7E

- [x] 不合法 patch 被拦截；渲染失败自动回退；损坏的最新快照在启动时自动修复，不白屏
- [x] Schema、patch、工具动作、回滚有自动测试（core 50、tool-pdf 3、App 23）
- [x] TypeScript 检查、lint、测试可通过

## 已知限制

- **实机点击验证未完成**：模拟器上验证了 App 能启动、打包（含 pdf-lib）无错误、首页和 AI 修改页渲染正确。点击类操作需要先运行 `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` 才能自动化，目前由 Jest UI 测试覆盖。
- SQLite 存储实现没有自动测试（Jest 无法运行原生 SQLite），与内存实现共用同一接口和语义。
- 加密 PDF 的提示没有自动测试（pdf-lib 无法生成加密 PDF 作为测试素材）。
- 工作流执行时使用设备当前时间；生成文件名的日期按设备时区。
- 文件只能通过分享面板导出；还没有删除文件的界面（删除需要单独设计并经用户确认）。

## 明确不做

见 §3「明确不做」：不在手机上执行 AI 生成的代码、不做工具市场与付费、不做后台自主行动和语音主界面、不生成多个独立 App。
