| 旅程                   | 状态 | 验证方式                                                                                      |

| B 安装预设 PDF 工具    | ✅   | Jest UI 旅程：安装 → 从首页打开 → 真实合并两个 PDF（3 页）→ 文件出现在列表 → 卸载后文件仍在   |

**模拟器实机验证（iPhone 18 Pro / iOS 27，Expo Go，2026-10-22）**：四个旅程全部手动走通。

- B：安装 → 系统文件选择器选两个 PDF → pdf-lib 在手机上合并 → 输入文件名 → 保存 → 系统分享面板导出。从 App 沙盒取出合并结果检查：3 页，顺序与选择顺序一致。
- C：通过 AI 简化 PDF 流程 → 预览（修改前 / 后）→ 应用 → 再次合并，无需输入文件名，自动保存为 `合并-2026-10-22.pdf`，页序正确。
- A：通过 AI 改首页标题和导航 → 「AI 修改」「历史」变为浮动按钮。
- D：从浮动的「历史」恢复到安装 PDF 之前的版本 → PDF 入口消失、所有文件保留；重新安装后文件重新出现在工具页。
- 完全退出 App 再打开，界面、已安装工具和文件都在（SQLite 持久化）。

## 用户数据（schemaVersion 3，2026-10-22）

- AI 可以搭“能记东西”的页面：数据表结构（8 种字段类型）+ 记录列表 / 快速添加表单 / 统计；内置记账、待办、读书清单、笔记模板。设计与决定见 DATA_DESIGN.md、D-036–D-043。
- 记录只由用户在页面上增删改；撤销、恢复历史版本、移除数据表都不改动记录。「设置 → 数据」：导出 CSV、不在界面里的数据、最近删除（30 天）。
- AI 读不到记录：端到端测试检查发给 Claude 的完整请求（DATA_DESIGN.md §10）。
- 评测集 40 例：Haiku 5.5 40/40（$0.013）。
- 模拟器实测（Haiku 5.5，自带 key）：「新建一个记账页面」生成数据表和页面 → 记一笔 → 统计和列表更新 → 编辑页 → 删除并撤销。测试后模拟器数据已恢复原状。发现并修复：键盘弹出时第一次点击被吞、键盘挡住按钮、新页面在修改说明里显示成 ID。

## 图片与富文本（schemaVersion 4，2026-10-22）

- 图片位：AI 放位置和版式，用户点按从私密相册选择器选照片；照片重新编码为 2048 像素 JPEG 并去掉元数据；可更换、移除、撤销。AI 看不到照片和文件名（端到端测试）。
- 文件列表只显示文档，不列出界面用的照片（D-051）。
- 富文本：粗体、斜体、https / mailto 链接（打开前确认）、列表；emoji 图标。决定见 D-044–D-050。
- 评测集 46 例：Haiku 5.5 46/46（$0.014）。
- 模拟器实测（Haiku 5.5）：生成粗体 + 三点列表的介绍、🏡 首页图标、横幅图片位 → 从相册选照片 → 更换照片。发现并修复：原图以 HEIC 全尺寸保存（改为重新编码）、Haiku 把「横幅」做成文字提示框（提示词规则 D-050）。测试后模拟器数据和照片文件已恢复原状。

## 直接编辑（2026-10-22）

- 不打字也能改界面（§5.3 可视化编辑的第一版）：点「编辑」或长按任意组件进入编辑模式 → 改文字、颜色、对齐、大小、上移 / 下移、隐藏、删除（先确认）、拖动排序（能移入 / 移出分组，拖到边缘自动滚动）。隐藏的组件在编辑模式里也看得到，可以重新显示。决定见 D-052–D-059。
- 编辑模式里的修改先放在草稿里，每一步都经过校验；点「完成」合成**一个**版本（历史里记为「手动修改」，提示条一次撤销回到编辑之前），点「取消」全部放弃。走和 AI 相同的修改协议。系统页面不可编辑，预览里长按无效，数据组件不改文字、不碰记录。
- Jest UI 旅程 12 例（`editing-journeys-test.tsx`）：长按进入编辑、改文字和颜色、「完成」才生成一个版本并可一次撤销；必填文字不能清空；多次改外观合成一处；隐藏后重新显示；删除前确认、「取消」放弃整份草稿；用箭头移入移出分组后合成一个版本；数据组件；独立页面的「编辑」；长按按钮不触发跳转；草稿 30 处上限和无效修改被拒；预览里长按无效。拖放位置计算和操作合并在 core 有单元测试（`arrange.test.ts`）。
- 评测（改了提示词和 core）：Haiku 5.5 46/46（$0.015）。
- 模拟器实测（iPhone 18 Pro / iOS 27，Expo Go）：长按标题改文字；长按 PDF 卡片打开菜单而不是进入工具页；「编辑」开关进入编辑模式，导航栏隐藏；把「添加工具」拖到页面底部（页面自动向下滚动）再拖回顶部（自动向上滚动），「完成」后只生成一个版本「编辑「首页」（1 处修改）」；长按进入编辑 → 换颜色（面板保持打开）→「取消」→ 确认放弃，界面和版本都没有变化；工具页右上角「编辑」；长按「开始」只打开菜单、不启动流程。测试后模拟器数据已恢复原状。
- 模拟器面板的触摸注入偶尔会把「松手」留到下一次触摸才送达（重新连接面板或再点一下空白处即可），这是测试工具的问题，App 本身没有。
- 未做：表单输入框上的长按保持系统文字选择（长按表单其他位置打开菜单，按设计）；分组在编辑模式里一律竖排显示；页面标题、图标、导航栏还不能直接编辑（仍用 AI 修改）。

## 风格能力（schemaVersion 6，2026-10-22）

- 为预设风格补齐主题能力：第三色可覆盖、深色模式单独配色、阴影色跟随配色；卡片新增新粗野 / 新拟物 / 黏土 / 毛玻璃 / 霓虹发光 / 金属六种样式；页面背景可以是渐变或极光（D-073–D-078）。除 Bento 不对称网格外，之前列出的热门风格都能做成预设。
- 12 个内置风格预设（D-079）：iOS 原生、Material You、杂志、马卡龙、自然、终端、赛博霓虹、黏土、新粗野、新拟物、液态玻璃、Y2K 千禧；说「换成杂志风」之类，AI 用 `applyThemePreset` 整套切换，可以再加微调（「霓虹风格但主色用粉色」）。
- 评测集：Haiku 5.5 52/52（$0.018），含套用预设和「预设 + 微调」。
- 模拟器实测（iPhone 18 Pro，iOS 27）：新粗野、新拟物、黏土、深色模式单独配色、极光 + 毛玻璃（系统 Liquid Glass）、渐变 + 金属、深色极光 + 霓虹发光都渲染正确；金属渐变的明暗分界原来太硬，已放宽。一套测试配色（深色极光里的青柠色）对比度 4.49，被校验器拦下并自动恢复到上一版本，换色后通过。测试后模拟器数据和外观设置已恢复原状。
- 模拟器实测：12 个预设在已有数据（含图片工具）上逐个套用，浅色和深色各截图，显示正确。
- 还不能做：纹理（木纹、纸张）、Bento 不对称网格。

## 已知限制

- SQLite 存储实现没有自动测试（Jest 无法运行原生 SQLite），已在模拟器上实机验证。
- 加密 PDF 的提示没有自动测试（pdf-lib 无法生成加密 PDF 作为测试素材）。
- 在 Expo Go 中，右上角的开发菜单按钮会盖住提示条的「✕」和部分「撤销」文字；正式构建中没有这个按钮。
- 提示条不会自动消失（保留「撤销」入口），需要手动关闭。
- 只在 iOS 模拟器上验证过；Android 未验证。Android 上毛玻璃卡片只是半透明、没有模糊（D-077）。
- 工作流执行时使用设备当前时间；生成文件名的日期按设备时区。
- 文件只能通过分享面板导出；还没有删除文件的界面（删除需要单独设计并经用户确认）。

## 明确不做

见 §3「明确不做」：不在手机上执行 AI 生成的代码、不做工具市场与付费、不做后台自主行动和语音主界面、不生成多个独立 App。
